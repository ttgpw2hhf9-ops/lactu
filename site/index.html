Jeton GitHub (synchro + robot)

Un seul jeton sert à synchroniser tes appareils (lus, « À lire », réglages) et à lancer le robot avec le bouton ↻. Il reste sur cet appareil : saisis-le une fois sur l'iPhone, l'iPad et le Mac. Pour le créer : github.com › nouveau jeton (type « Fine-grained »), dépôt lactu seulement, droits Actions : Read and write et Gists : Read and write.
